## Sports Celebrity Image Classifier

This project is a web-based **Sports Celebrity Image Classification** system that uses machine learning and computer vision techniques to identify famous sports personalities from images. Users can upload an image through the web interface, and the model processes it using a pipeline that includes image preprocessing, feature extraction, and classification to predict the celebrity.

The application demonstrates how AI can automate image recognition tasks, making it useful for applications like media management, sports analytics, and content recommendation systems. It is deployed as an interactive web app, allowing real-time predictions directly in the browser.

🔗 **Live Demo:** https://sports-celebrity-classifier.onrender.com/

### Features

* Upload and classify celebrity images
* Real-time prediction via web interface
* Pre-trained machine learning model
* Image preprocessing and feature extraction pipeline

### Tech Stack

* Python
* Machine Learning (Scikit-learn / TensorFlow)
* OpenCV
* Flask (or similar backend framework)
* HTML, CSS, JavaScript

### Usage

1. Open the live demo link
2. Upload an image of a sports celebrity
3. View the predicted result instantly
